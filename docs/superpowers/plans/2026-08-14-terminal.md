# 내장 터미널 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ConPTY(pywinpty)+pyte 기반 완전 터미널을 하단 도크로 제공 + 외부 관리자 셸.

**Architecture:** `core/terminal.py` 가 pty 프로세스와 VT 화면 상태(pyte)를 소유하고,
UI(`ui/terminal_pane.py`)는 50ms tick 에서 generation 이 바뀐 경우만 화면을 다시
그린다(기존 pull 모델). 키 입력은 순수 함수 `encode_key` 로 VT 시퀀스화해 pty 에 쓴다.

**Tech Stack:** pywinpty 3.x (`winpty.PtyProcess`, dimensions=(rows, cols)),
pyte (`HistoryScreen`/`Stream`, Char=(data,fg,bg,bold,italics,underscore,strikethrough,
reverse,blink)), PySide6. 스파이크로 echo 왕복 검증 완료 (2026-08-14).

**Spec:** `docs/superpowers/specs/2026-08-14-terminal-design.md`

## Global Constraints

- 스펙 §2 표의 확정 사항 전부. 테스트는 selftest/uitest 하네스, `tr()`+i18n_en, ruff 110.
- pywinpty 는 Windows 전용 — requirements 는 `pywinpty>=2.0; sys_platform == "win32"`,
  코드는 import 가드(`TERMINAL_AVAILABLE`), 테스트는 가용할 때만 pty 구간 실행.
- 커밋 메시지에 큰따옴표 금지 (PS 5.1 인자 전달 문제).

### Task 1: TerminalBuffer + encode_key (플랫폼 무관 코어)

**Files:** Create `core/terminal.py` · Test `selftest.py` `test_terminal_core()`

**Interfaces (Produces):**
- `TerminalBuffer(cols, rows, history=5000)`: `.feed(str)`, `.snapshot() -> Frame`,
  `.resize(cols, rows)`, `.page_up()/.page_down()`, `.text() -> str`,
  `.generation: int`
- `Frame(rows, cursor, generation)`; row = list of `Run(text, fg, bg, bold, reverse)`
- `encode_key(key: int, text: str, modifiers) -> str` (Qt 키 → VT. Qt 의존 없이
  int/문자만 받는다 — core 에 두되 Qt enum 값은 호출부가 넘긴다)
  → 설계 수정: Qt 상수 의존을 피하려 `encode_key` 는 **ui/terminal_pane.py** 에 두고
  Qt 없는 매핑 테이블만 core 에 둔다… 대신 GUI selftest 에서 검증한다.
  (core 는 Qt 를 모른다 원칙 유지)
- `TERMINAL_AVAILABLE`, `TERMINAL_ERROR`

**Steps:**
