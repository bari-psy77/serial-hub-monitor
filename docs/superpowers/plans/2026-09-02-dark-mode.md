# 다크모드 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 라이트/다크 테마를 즉시 전환하고, UI·로그 본문·터미널 색이 모두 함께 바뀐다.

**Architecture:** 색을 저장하지 않고 **그릴 때 결정한다.** `ansi.parse()` 는 해석된 hex
대신 의미 토큰(SGR 코드 또는 리터럴)을 담고, 팔레트는 `theme`/`ansi`/`filters` 세 모듈이
테마별 2벌로 들고 있다가 `set_theme()` 으로 갈아끼운다. UI 는 전부 `from . import theme`
(모듈 참조)라 토큰 교체가 그대로 따라오고, QSS 재적용으로 덮이지 않는 것(인라인 스타일·
폰트 크기·하이라이터 포맷)만 `refresh_theme()` 로 다시 바른다.

**Tech Stack:** PySide6(QSS·QSyntaxHighlighter·QTextCharFormat), Qt 비의존 core.

**Spec:** `docs/superpowers/specs/2026-09-02-dark-mode-design.md`

## Global Constraints

- 선택지는 **라이트/다크 2택**, 기본값 `light`. 저장은 `settings.json` 의 `theme` 키.
- **즉시 적용** (언어는 재시작 필요 — UI 라벨로 구분해 표시).
- 하이라이트 색 **이름은 프로파일 식별자**다. 두 팔레트의 키 집합이 같아야 한다.
- 사용자 문구는 `tr('한국어 원문')` + `core/i18n_en.py`. 모듈 최상위 `tr()` 금지.
- **모듈 최상위에서 색을 값으로 굳히지 않는다** (`tr()` 과 같은 규칙). 값 임포트
  (`from .filters import HIGHLIGHT_COLORS`) 금지 — 함수로 조회한다.
- 검증 3종: `python selftest.py --gui`, `python uitest.py`,
  `python -m ruff check . --select E,F,W,B,ARG --line-length 110`.
- 저장소는 CRLF. 커밋 메시지에 큰따옴표 금지(PS 5.1). 커밋 꼬리:
  `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`

from ..core import ansi

_COLOR_CACHE: dict[tuple[str, bool], QColor] = {}

def _span_color(token: str, background: bool) -> QColor | None:
    """토큰 → QColor. 캐시해 두면 hex 문자열을 매번 파싱하지 않는다 (8배 빠름)."""
    if not token:
        return None
    key = (token, background)
    color = _COLOR_CACHE.get(key)
    if color is None:
        hex_value = ansi.resolve(token, background=background)
        if not hex_value:
            return None
        color = QColor(hex_value)
        _COLOR_CACHE[key] = color
    return color

```python
def apply_theme_change(self, name: str) -> None:
    """테마 전환. QSS 재적용만으로는 부족한 것들을 순서대로 되바른다 (약 1초)."""
    QApplication.setOverrideCursor(Qt.WaitCursor)
    try:
        applied = theme.set_theme(name)
        ansi.set_theme(applied)
        filters.set_theme(applied)
        theme.apply_theme(QApplication.instance())
        for widget in self._themed_widgets():        # Card·설정 창 등 인라인 스타일
            widget.refresh_theme()
        for pane in self._all_panes():
            pane.refresh_theme()
        for dock in self.terminal_docks:
            dock.refresh_theme()
        config_mod.set_theme_setting(applied)
        diag.info("app", f"테마 전환 -> {applied}")
    finally:
        QApplication.restoreOverrideCursor()
    self.tick()
```
