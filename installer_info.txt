Serial Hub — 포트 통합 시리얼 모니터

VS Code Serial Monitor + Tera Term + MobaXterm 세 툴을 하나로 대체합니다.
User CLI / Matter 로그 / Matter shell 콘솔 3개를 한 화면에서 보고, 필터드뷰로
원하는 값만 따로 보고, 수신을 멈추지 않고 로그를 계속 저장합니다.

설치 전 알아둘 것
-----------------

* Python 을 설치할 필요가 없습니다. 필요한 것이 모두 들어 있습니다.
* 기본은 사용자 단위 설치라 관리자 권한이 필요 없습니다.
  (이 화면 전에 "모든 사용자용" 을 골랐다면 관리자 권한이 필요합니다)
* 시리얼 포트(COM)는 한 프로그램만 쓸 수 있습니다. 같은 포트를 잡고 있는
  Tera Term / VS Code Serial Monitor 는 닫고 쓰세요.
* 설정과 프로파일은 Windows 관례대로 %LOCALAPPDATA%\SerialHub 에 저장됩니다.
  (설치 폴더에 portable.txt 를 만들어 두면 그 폴더에 저장해 USB 로 들고 다닐 수 있습니다)
* 수집한 로그를 어디에 저장할지는 다음 단계에서 직접 고릅니다.

설치 후 처음 할 일
------------------

1. 시작 메뉴의 "설치 상태 점검" 을 한 번 실행하세요.
   COM 포트 열거·화면 라이브러리가 이 PC 에서 정상인지 확인합니다.
2. Serial Hub 를 실행하고 툴바의 [연결] 을 눌러 포트를 지정합니다.
   어느 COM 이 어느 콘솔인지 모르면 [전체 Probe] 를 누르세요 — 실제 명령을
   보내지 않고 역할을 판정해 매핑을 제안합니다.
3. [전체 연결] 을 누르면 그때부터 로그가 자동 저장됩니다.
   저장 위치는 설치할 때 고른 폴더 아래 날짜별(MMDD) 폴더이고,
   프로그램의 [설정 > 로그 설정] 에서 언제든 바꿀 수 있습니다.
